# Using the course book

## Read online

Use the sidebar or search to find lectures, equations, worked examples, and self-check quizzes. You do not need a GitHub account to read a public course website. Python code shown on these pages does not execute on the website.

## Run a notebook

**Google Colab:** click **Open in Colab** above a notebook page's title. The matching notebook from this course's GitHub repository opens in a new tab. Sign in to Google, save your own copy, and run the cells from the top. The first setup cells install packages and load the included datasets. Colab requires an internet connection. You can also choose **Colab** from the rocket menu in the toolbar.

**Your computer:** download the materials below and unzip them. With Python 3.11 or 3.12 installed, open a terminal in the extracted folder and run:

```bash
python -m pip install -r requirements-student.txt
python -m jupyterlab
```

Open a notebook in the `dsmles` folder and run its setup cells first. The notebooks include the small datasets they need, so they do not fetch course data from the original CMU repository.

{download}`Download notebooks and datasets <_static/downloads/cbe4427-notebooks.zip>`

Some optional topics need additional packages, services, or computing resources; see their notebooks. The quizzes give practice feedback and do not submit grades.

## Save your work

Sign in with your Google account, choose **File → Save a copy in Drive**, and work in your own copy. Download a backup when you finish. Your changes do not update the course website. Reading or answering a quiz here does not save a submission for the instructor.

## Course requirements

See [Course information](course-information.md#assessment) for the undergraduate and graduate assessment schemes. The 13 tutorials are practice resources; the five assessed assignments are specified separately on OWL Brightspace. Follow your official course outline and instructor announcements for deadlines, permitted AI use, and submission instructions.
